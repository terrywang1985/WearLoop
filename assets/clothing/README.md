# WearLoop 示例衣物素材

14 件示例衣橱的图片通过 **内置 imagegen** 生成，为接近商品摄影的 AI 示例素材，并非用户真实衣物照片。

`generated/*.png` 是完整原图；App 使用当前目录的同名 `.webp`。所有原图及 WebP 已检查 RGBA 透明通道，背景不是棋盘格或纯色伪透明。运行素材以 640×640 编码，14 张合计约 0.9 MB；原始文件同时保留在 Codex generated_images。

统一提示词方向：单件完整衣物或成对鞋履、平铺正面或鞋履俯视角度、真实布料/皮革纹理、左上方柔和中性光、透明背景；无模特、衣架、人台、文字和标识。精确的逐张提示词、生成模式和源文件记录见：

- [基础款四件](prompts-basics.json)：白T、条纹衫、牛津衬衫、牛仔裤。
- [外套与裙装](prompts-outerwear.json)：风衣、西装、碎花裙、围巾。
- [下装与鞋履](prompts-bottoms-shoes.json)：卡其裤、百褶裙、小白鞋、乐福鞋。
- [针织与包](prompts-knit-bag.json)：针织衫、帆布包。

`tools/prepare_demo_assets.py` 只缩小尺寸并转换格式，保留透明通道，不做去背景或视觉修改。App 内用户上传照片优先；只有默认示例衣物使用这些素材，其他无照片的个人衣物继续显示分类插画。
